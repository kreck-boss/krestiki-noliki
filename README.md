# Крестики-нолики

Практическая работа №2 по разработке консольной игры на C#.

## Требования

- два игрока: `X` и `O`;
- проверка ввода и занятых клеток;
- определение победы по строкам, столбцам и диагоналям;
- определение ничьей;
- повторный запуск партии без перезапуска приложения.

Разработка выполняется по функциональным веткам с последующим объединением через Pull Request в `main`.
